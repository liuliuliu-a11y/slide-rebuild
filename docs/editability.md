# 哪些内容可以修改

“可编辑”按实际用途区分，不要求把每条科研曲线拆成 PowerPoint 对象。

| 内容 | 推荐交付方式 | 修改位置 |
|---|---|---|
| 标题、正文、数字、标签 | 原生文本 | PowerPoint |
| 参数表、普通数据表 | 原生表格 | PowerPoint 单元格 |
| 流程框、箭头、结构关系 | 原生形状与连接对象 | PowerPoint；适用时绑定端点 |
| 科研、工程、仿真曲线 | MATLAB / Python 数据与脚本 + SVG / 高清 PNG | 在源工具改数据或样式后重新导出；PPT 内整体移动、缩放 |
| 明确需要在 PPT 内改数据的商务图表 | 原生 chart + 嵌入数据 | PowerPoint 图表数据编辑 |
| 简单公式 | 可编辑文本或公式对象，标明实际类型 | PowerPoint；文本不等于 Office 公式对象 |
| 复杂公式 | 根据任务约定保留公式源或公式对象 | 原始公式工具或 PowerPoint；图片不冒称可编辑公式 |
| 设备、照片、插画 | 独立图片资产 | PowerPoint 中排版；内部细节在图像工具修改 |

## 科学绘图建议

保留原始数据、坐标单位、图例和绘图脚本。优先提供 SVG，兼容性不稳定时使用按最终尺寸生成的高清 PNG；最终仍要在 PowerPoint 中核对字体、清晰度和裁切。

SVG 是矢量格式，但不自动等于原生数据图表。整张图可选中移动，也不等于可以在 PPT 内修改每个数据点。

[公开示例](../examples/thermal-storage-demo/README.md) 提供相同数据的 MATLAB 与 Python 重绘脚本；PPT 中使用 MATLAB 导出的 PNG。
