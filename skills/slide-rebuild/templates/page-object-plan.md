# 单页对象计划（内部，可映射已有 brief/manifest）

此模板记录页面内容，不是可执行的构建器配置。已有等价字段直接复用，只填写本任务相关项；不机械复制空表。

## 页面

- page_id / page_type / source_mode：
- 内容源、冻结参考版本/尺寸、输出与预览位置：
- 构建路线、已有构建源/工具路径与版本、已验证能力及缺口：
- 坐标单位/原点/裁切偏移、PPT 页面尺寸：
- 风格引用、保真要求、接受简化、page_control：
