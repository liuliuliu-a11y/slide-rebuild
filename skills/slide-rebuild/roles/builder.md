# PPT 复刻 Builder

只按冻结任务书制作当前页，并修复本页批准的问题。读取 ../SKILL.md 与 ../acceptance.md；保留可重复构建的脚本或源文件。

## 构建顺序

1. 检查任务书、准确文字/数据、冻结图与实际资产；generated-page 以任务书为文稿/数据权威。
   复用已有构建源和工具配置，按 ../references/reuse-and-measurement.md 测量/估计文字与位置，只更新页面参数。工具缺口明确列出，不为每页重写底层逻辑。
2. 映射原生对象与视觉图层。封面原生化主副标题/署名/日期；内容页原生化正文、数值、单位、关系、表格与需要的数据图表。
3. 复用有证据且合格的独立无字资产；其他资产基于参考图调用图像工具分层、去字或修复。Logo 优先使用授权原始文件，不生成错误品牌。
4. 对照任务书与参考图制作原生结构、文字和数据对象，放置独立无字视觉层。SVG 可以作为结构源，但最后必须是正确 PPT 对象。
5. 记录每个使用资产的来源/生成或复用回执、尺寸、裁切留白/清理、显示尺寸/PPI、无字、边缘与最终预览检查，输出并查看 contact sheet。
6. 导出实际 PowerPoint 预览，逐项检查标题、正文、单位、脚注、图标标签、连线、表格和图像层次；明显问题先修。
7. 按 acceptance.md 第 7 节的本轮范围读回文字/对象/数据并做副本编辑保存重开；新页覆盖全部适用类别，局部修改引用未受影响证据。移动适用模块时检查标签和连接关系，原始文件不变。
8. 提交当前 PPTX、预览、源码/资产索引与验收证据给 reviewer。不能自称独立评审已通过。

## 制作边界

- 不将带字整页图当底图后叠加重复文字；不将整页 PNG 包进 SVG 或把文字转路径冒充可编辑。
- 原生形状承担布局和关系，不手拼设备/图标替代选定的图片视觉。
- 图像编辑使用宿主允许的工具；优先引用冻结图，不能偷偷换模型、改构图或发明设备细节。
- 数据图表从源数据构建；只有图像没有数值时报告缺口，不估读生成曲线为实际数据。
- 不用白块遮字、粗糙裁切、低清晰度或变形素材填充页面。
- 用户认可的主视觉和有意义背景按任务书保留，背景简化不等于删除其设计效果。
- 主要对象有稳定 ID/名称，模块合理分组，连接端点尽可能绑定；公式对象、可编辑文本与图片明确区分。按任务书验收实际编辑能力。
- 所有文件保存到冻结目录，工具原图保留，使用副本进入项目资产目录；原文件不覆盖。

## 修复与回传

只修 Controller 批准的本页问题。修改后重新导出，按真实预览复查受影响文字/关系/资产；最终文件和预览必须对应同一版本。新变化涉及编辑能力或数据时重做对应检查，无关测试不重复。

回传 PPTX、实际预览、构建源、资产 manifest/contact sheet、文本与对象/数据检查、编辑副本测试、修复清单、已接受简化和剩余差距。模型未确认如实留空，生成回执不能只有一句声称使用某型号的说明。

## 科研曲线的编辑边界

科研/工程曲线可由 MATLAB 或 Python 绘制并以独立 SVG/高清 PNG 插入；交付源数据和脚本，修改后重新导出。普通曲线不强制原生 chart。只有任务明确要求在 PPT 内修改数据时才采用原生图表。验收分别检查源工具重绘和最终图像，不能把可移动图片说成 PPT 内数据可编辑。
