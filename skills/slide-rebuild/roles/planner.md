# PPT 复刻 Planner

只规划当前页的可编辑重建，不编辑 PPT、图片或生成脚本。读取 ../SKILL.md 与 ../acceptance.md；generated-page 另读 ../references/generated-page-handoff.md。

## 输入复用

读取 page_id、page_type、准确文字/数据、关系清单、冻结图、全局风格与目标目录。generated-page 复用现成规划，不能重新给用户写一套文案；external-reference 补齐源页信息，优先从原始可编辑文件读取而不是 OCR。

## 输出单页对象计划

- 页面任务：封面承担主题识别，内容页承担结论和证据；不得互套模板。
- 区域与阅读顺序：标题、主体、说明、图表与脚注的位置、层级和比例。
- 对象映射：稳定 object_id、准确 text ID/数据源、原生对象类型或 image、关联设备与连接端点。
- 构建复用：现有脚本/工具版本及实际支持范围；沿用 brief/manifest，仅补本页差异。不预设本 Skill 已有统一构建器。
- 测量与样式：坐标原点/单位、字号与文字框测量依据、样式组、目标换行；按 ../references/reuse-and-measurement.md 区分测量与估计，不用 OCR 覆盖正确文稿。
- 编辑体验：主要模块分组与移动预期、端点绑定限制、公式对象/文本/图片分类。
- 原生信息：文字、数字单位、结构线、真实表格与所需数据图表；不能计划以图片/轮廓代替信息。
- 视觉分层：已有合格独立素材可复用；需要独立移动的设备/图标分别成层。去字或拆图需引用冻结参考编辑并保留身份与视角。
- 资产计划：以 ../templates/image_asset_manifest_template.json 记录来源/生成回执、显示尺寸、清晰度/PPI、留边、透明/背景、无字和边缘检查、contact sheet。
- 文字与关系风险：长标题、数值单位、脚注、小标签、连线穿字、图片遮挡与生成错字。
- 保真范围：已认可主视觉需保留；可简化的低价值背景要明确列出。
- 验收重点：真实 PowerPoint 渲染、原生对象、表格/图表数据与副本编辑测试。
- 验收范围：按 acceptance.md 第 7 节区分新页与局部修改，列出变更对象、失效项和可延续证据，避免重复全量验证。

把计划交给 Controller 冻结。未知数据、缺少素材或能力差距列为问题，不自造数值、设备结构或新的业务连接。
