# 接收已生成页面

适用于已授权的图像先行流程交接。它复用规划，不替代本 Skill 的真实编辑与视觉验收。

## 进入复刻前

父流程应已完成所有页面的图片生成、整套检查与版本冻结，当前处于 reconstruction 阶段。读取父 deck_manifest 和 image_deck_review 或等价记录，核对以下语义（字段名可映射，不要求重建已有文件）：

- status=passed，存在可读的整套检查记录，reviewed_roster_version 与当前目录一致。
- references 覆盖目录的全部 page_id，图片存在且版本/哈希一致；全部单页任务书版本与冻结记录相符。
- 整套检查应已核验每页的真实生图模型输出与生成记录；当前页核对 generation_tool、提示词、tool_receipt、original_output 及原始哈希，确认记录能追溯到采用的冻结图。复用允许引用有效历史记录；代码制图、排版截图或无法追溯的图不能冒充 generated-page 输入。
- 记录上游实际使用的提示词/生成工具和回执，并对应当前冻结图；只有提示词、代码图、排版截图或手填型号不能冒充真实生成记录。不要求安装特定命名的提示词或图像 Skill。
- 当前页 state 为 reference_frozen，或属于可解释的本页续做状态；仅 image_ready 不足以开始复刻。
- 整套记录为 stale、未齐图、存在未解决冲突或缺少检查证据时，反馈父流程完成相应检查，不提前重建。

以上只适用于已授权父流程的 generated-page 交接，独立 external-reference 无需补做整套图片阶段。

## 输入优先级

1. 用户当前修改和已确认的事实/数据。
2. 单页任务书的 text_inventory、表格/图表源数据、relationships 与可编辑边界。
3. 已冻结的整页参考图：决定构图、比例、字级、颜色和主视觉。
4. OCR/图像识别只补缺项，不能覆盖上游准确文字，也不能从插画推断设备结构或控制连接。

内容与参考图冲突时，先修内容源/参考或记录明确纠正项；不能两边各照抄一次造成重复、错字或数值冲突。

## 必需交接

- page_id、页序、page_type、页面任务与全局风格引用。
- 父 manifest、整套图片检查记录及目录版本；当前页 brief_version 和冻结记录身份。
- 当前页任务书；含每条准确文字的 ID、完整内容、层级、区域和对应对象。
- 冻结参考图的绝对路径、版本、尺寸、哈希与采用依据。
- 整页图对应的真实模型调用记录与原始输出；不是只有资产清单、提示词或手填型号名称。
- 上游提示词/生成工具、版本或模式（如有）及实际回执；复用图引用原始记录，不编造实际型号。
- 表格/图表原始数据、单位和是否要求数据编辑；没有数据不得猜测。
- 关系端点 ID、连接方向/标签与事实依据。
- 原生对象清单、独立图片层清单、背景保留要求、已有生成回执/资产清单。
- 单页输出、预览、工作资产目录、继承的 page_control 与父任务授权范围。

已有上游任务书可直接充当 planner 内容输入；planner 只添加重建所需坐标、对象映射、资产分离、字号风险和验收重点。缺少准确文稿时回查原资料，不要求用户重新抄写已有文档。

## 按页类型重建

| 页面 | 应保留的表达 | 原生信息 | 视觉资产 |
|---|---|---|---|
| cover | 主题识别、主视觉、标题留白 | 主副标题、准确署名/日期 | 独立主视觉/背景与原始品牌资产 |
| content | 一句结论、证据、阅读顺序、事实关系 | 正文、数字单位、关系线、表格、图表数据 | 无字设备、图标、复杂插画 |
| divider / ending | 用户指定的转场或结束任务 | 标题、必要署名/联系方式 | 仅实际需要的视觉 |

不得在复刻阶段自动给封面增加指标卡，也不得把内容页转换成只剩场景大图。用户选中的场景层次属于视觉要求，背景简化不能破坏其主视觉。

## 从整页图到可编辑对象

1. 按 text_inventory 建立原生文字，并按对象 ID 关联到设备、数据与连接线。
2. 结构与关系用原生形状/连接对象；表格为真表格，数据图表从源数据制作。
3. 已有合格独立无字图片层直接复用其生成回执；需拆分时用冻结图作为编辑参考，分别取得无字场景/设备/图标。只需要组合移动的视觉可以保留在一张无字资产中；要求独立移动的对象必须分层。
4. 去掉文字、关系箭头、数据图表后的视觉层才可嵌入。绝不能在带字整页上加一层相同原生文字后声称重建。
5. 复查画面保真与可编辑文字的字级、位置、段落、颜色、数值单位、标注关系。准确原文优先于生成图中的错误写法。

不对每个已生成元素强制重复生图。生成记录可来自上游，但必须真实、指向所使用素材。生成图回执没有型号时不得补造型号；选择复用也不能消除严格型号要求的缺口。

## 回传与续做

回传本页 PPTX、实际渲染预览、原生对象与数据检查、编辑副本测试、资产 manifest、reviewer 结果、差距和 checkpoint。生成图、PPT 和任务书使用同一 page_id。

新页按 acceptance.md 建立适用的完整页面基线；后续局部修改按其第 7 节回传新增检查和有效证据引用，不能把旧测试冒称本轮全量实测。复用既有构建源、对象 ID 和样式，只更新受影响内容，不要求重写页面脚本或运行整组工具基准。

父任务在授权范围内继续复刻已冻结的下一页。保存 checkpoint 不自动要求再次批准；只有用户要求逐页确认时暂停。本阶段可为当前页去字、拆层和修图，不启动尚未规划的整页设计。

后续小改优先修改原生文字/布局，关键构图才重生参考图。影响冻结文稿、数据或图片的变更反馈父流程，将整套检查标为 stale，修正并复查受影响页及必要的跨页一致性后更新冻结记录，避免下一轮复刻读回旧数值。保留未受影响且仍有效的已验收成果。
