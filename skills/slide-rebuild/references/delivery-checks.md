# 交付检查

此文件提供自包含的交付检查方法，不要求安装特定工作区扫描器。

1. 用最终 PPTX 在 Microsoft PowerPoint 中实际打开、导出预览，记录所测文件版本和结果；在副本执行 acceptance.md 规定的适用编辑并保存重开。工具不可用时明确尚未验证。
2. 对照准确文稿与原始数据检查最终页面和演讲备注，保持正文、数据、图例、公式及关系的语义完整。
3. 正式页面和演讲备注只保留目标受众需要的信息，移除机器路径、账户信息、命令、工具日志、制作计划及内部检查说明。用户明确要求的公开引用、合法品牌资产和正式注释可以保留。
4. 将来源路径、素材回执、构建源和验证记录放在独立工作目录；对外只交付用户指定的文件。发布示例前确认素材/文字/数据可公开，不把私人项目打包为示例。
5. 可利用宿主已有文本提取与卫生扫描工具，但扫描通过不能代替实际渲染、事实核对或编辑检查。无法可靠读取的区域明确列为未检查。
6. 交付说明区分当前验证与沿用证据、原生对象与图片层、单页与整套、已完成与未确认项。检查通过即交付，不增加无关复核轮次。
