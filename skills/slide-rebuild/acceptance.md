# PPT 复刻验收标准

验收单位为当前页；页数与顺序按已选范围，不要求单页试作覆盖整份原始材料。generated-page 在父流程整套图片检查与冻结后进入，以准确任务书为内容权威、冻结图为视觉参考。独立 external-reference 无需上游生图。图片样张通过目视检查不等于 PPT 已通过本标准。

## 1. 内容与页类型

- 全部要求的文字、数字、单位、脚注、表格、图例、关系和结论有对应对象，未传播生图/OCR 错误。
- 封面准确呈现主副标题、署名、日期和授权品牌素材；不能臆补空缺信息或添加正文指标。
- 内容页保留结论、支撑数据、事实边界和正确连接关系；定性示意不能冒充测量或计算结果。
- 图表来自真实源数据；无法取得数据时报告能力/来源缺口，不能从生成图猜值。
- 合并后的页序与页数按 manifest 复核，已验收单页与完整 deck 的范围明确区分。

## 2. 原生可编辑信息

- 标题、正文、小字、数字、单位、标签、图例、署名和日期是原生文本。
- 流程框、结构容器、主要关系线/箭头是原生形状或连接对象。
- 表格必须是真正 PowerPoint table object。
- 要求数据编辑的图表必须有原生 chart 与可编辑数据，并验证数据关联；只有图形可移动不算数据可编辑。
- 公式尽可能保留可编辑表达，记录为公式对象、可编辑文本或图片；文本上下标不等于公式对象。实际限制必须明确，用户要求的编辑能力未满足时不能只写 warning 后通过。
- 需要一起移动的模块应合理分组或有等效操作方式，主要对象有稳定 ID/有意义名称。适用时在副本移动模块或节点，核对标签不散开、连接关系仍符合任务书；不以对象很多证明好编辑。
- 连续曲线优先保持完整路径；端点绑定与数据联动分别核验，不把曲线顶点编辑冒充原生数据图表。工具限制如实列出，不能降低已约定的编辑要求。
- 不接受带字整页图、文本截图、表格截图、轮廓文字或 PNG 包装的 SVG 冒充可编辑重建。图片背景不得残留将被原生对象重复覆盖的说明文字、关系箭头或数据图表。
- 复杂设备、图标、场景与插画可保留独立无字图片层；不宣称图片中的设备每个细节都能用 PPT 修改。

## 3. 图片资产质量与证据

使用 templates/image_asset_manifest_template.json 或等价已有记录，不重复填表。每个嵌入图片至少记录：用途、来源/生成/复用依据、实际使用文件、源图尺寸、裁切/清理方式及留边、输出尺寸、PPT 显示尺寸、有效 PPI、无字/边缘检查与 contact sheet。

- provenance_kind 可使用 new_generation、upstream_generated_reuse、authoritative_source_asset。复用需要原始回执或明确的授权原始素材依据，不能仅凭文件名编造“image2 生成”。
- 默认清晰度目标：小图标/细线资产 220 PPI，大型视觉 180 PPI，细线截图/图示优先 300 PPI。低于默认目标需按任务已确定的输出尺寸判断并明确差距；肉眼可见模糊、像素化或不可读是 Blocking，不能仅放大像素伪造有效细节。
- 从原始或更高质量源处理，保持比例与边缘留白；不得非等比拉伸、切断图标边缘/阴影/线条、留白块遮挡、残字、伪文字、水印、去底毛边、脏背景或明显拼接缝。
- 去字、分层与修图按宿主工具约束执行；已有合格独立资产允许复用，不机械要求重复生图。
- 最终视觉资产不含业务说明文字；授权原始品牌标识允许按任务书保留，不用它替代正文。
- 每页 contact sheet 展示全部使用资产，以实际或 2 倍显示尺度检查，且最终 PPT 实际摆放仍清晰、无变形。
- 生成回执区分 requested_model 与 actual_model；未返回实际型号记录 null。严格型号要求缺少证据不能判为满足。

## 4. 实际视觉与布局

- 用最终 PPT 经 PowerPoint 导出的真实预览对照冻结参考，检查标题层级、配色、比例、间距、阅读顺序与主视觉。
- 文字不溢出、裁切、错误换行、被遮挡或与关系线冲突。
- 数字单位、图标标签、表格行列对齐；脚注和页脚可读。
- 已认可且要求保留的场景/主视觉不能因“背景降权”被删除。简化低价值背景需符合冻结任务书。
- 修改后重新导出并复查受影响区域；最终预览与最终文件一致。无新变更或疑点，不反复扩大验收。

## 5. 文件、数据与编辑实测

- 实际 PowerPoint 能打开、保存/重开且导出预览；若工具不可用，清楚说明未能确认，不能用静态解析替代通过。
- 新页读回全部必要文字、对象类型、表格数据、原生图表及工作簿关系；对象总数只是证据之一。后续修改按第 7 节限定新增检查，延续证据不能冒充本轮全量读回。
- 新页在副本修改一段文字、移动适用的结构对象或模块、修改适用表格/图表数据值，再保存重开，验证编辑保留；没有该对象类别时记不适用。后续修改按第 7 节重测受影响类别。原始文件不变。
- 合并保留每页原生对象、母版与媒体/数据关系，最终 deck 再做实际打开/渲染和关系检查。
- PPTX 与预览在 output，资产/脚本/回执/QA 在对应项目/work；工具原图保留、实际使用素材有项目内副本。
- 正式页面和演讲备注不包含内部路径、工具日志或制作说明；按 references/delivery-checks.md 检查；现有工作区检查器可辅助，未检查项目不能冒称通过。

## 6. 独立复核与 checkpoint

Reviewer 基于最终预览、任务书、资产和编辑证据只读判断，使用 Blocking / Polish / Accepted simplifications。宿主允许时使用 reviewer 子代理；不可用时明确独立复核阶段的 fallback。不能把 Builder 自查称为独立签收。

有 Blocking 留在当前页并报告具体差距；无 Blocking 保存 checkpoint。generated-page 按父任务继承的 page_control 推进：用户要求逐页确认时展示后等待；完整或阶段连续执行已获授权时按 continuous_serial 复刻下一页，不重复索要许可。独立 external-reference 按当前授权范围推进，不因保存 checkpoint 自动扩大制作范围。

不能完全满足的项目按 blocked by source/material/tooling、accepted simplification、not implemented yet 逐页记录。完成一个 checkpoint 不等于完整 deck 验收通过。

## 7. 按变更影响验收

验收深度与影响相匹配。最终文件的内容与可编辑底线始终有效，但允许有依据地沿用未受影响证据。

| 本轮工作 | 必须新增的检查 | 可复用的内容 |
|---|---|---|
| 新参考页首次复刻 | 本标准适用项：内容/对象读回、真实渲染、视觉核对、副本编辑、复核与卫生检查 | 工具已有能力验证、仍适用的资产来源证据；不能代替新页验收 |
| 已验收页修改文字 | 新文字准确性/对象读回、最终真实渲染及相邻换行/遮挡检查、副本文字编辑保存重开、卫生检查 | 未受影响的资产、表格/图表编辑、模块移动证据 |
| 替换图片或调整局部布局 | 最终真实渲染、比例/清晰度/遮挡/相关标签与连接检查；受影响对象的副本移动保存重开；适用内容读回与卫生检查 | 未受影响的文字/数据编辑及资产证据 |
| 修改表格、图表或连接结构 | 相应数据/对象/关系读回、真实渲染、相应副本编辑及关系保持测试、卫生检查 | 无关对象类别的有效证据 |
| 修改共用构建/渲染/合并工具 | 受影响类别的固定样例检查，见 references/benchmark-evaluation.md；实际交付页仍按本标准核验 | 未受影响类别的既有基准结果 |

修改字体/主题、母版或构建方式可能影响整页/多页，不能按单个对象的小改处理。影响不明、新失败或旧证据缺失时扩大到相关页面/对象类别；不用每次重跑所有样例。

记录旧证据适用的对象、源数据、素材与工具环境，及其未变依据。旧记录继续保持原版本身份，禁止修改日期/哈希使其看似新测。最终真实预览必须对应当前 PPT；素材未变可沿用 contact sheet，但仍核对最终摆放。

## 8. 质量评价与停止条件

| 维度 | 可观察证据 |
|---|---|
| 内容准确 | 具体错漏字、数字/单位/公式、连接方向和数据不一致项 |
| 视觉还原 | 标明区域的尺寸/位置/字号/换行/配色差距；有测量时注明单位和依据 |
| 编辑能力 | 实际对象类型、数据关联、公式表示方式及副本编辑结果 |
| 编辑体验 | 模块移动后标签/连接关系是否保持、是否存在影响修改的碎片对象 |
| 效率 | 实际耗时、修复/生图次数；缺记录不估报，无需为普通小改另建统计系统 |

像素差异图可帮助定位；抗锯齿或字体替换会改变像素，不能单凭相似度判定成败。对象总数、工作量或流程完成不等于质量。

内容错误/缺失、必要编辑能力不满足、明显不可读或必需证据缺失属于 Blocking，不能用其他指标抵消。可接受的细微风格差异归 Polish；本页没有 Blocking 且适用检查完成就保存 checkpoint，不因追求无阈值的满分重复生图或重建。用户另有明确保真要求时按任务书判断。
